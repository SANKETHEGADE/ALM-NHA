## 🚀 Overview & ALM Pipeline Role

This module implements a **100% Non-Whisper Multilingual Speech-to-Text and Acoustic Representation Subsystem** supporting **7 target languages**:
1. **Hindi (`hi`)** — Devanagari script & Indic normalization
2. **Telugu (`te`)** — Telugu script
3. **Tamil (`ta`)** — Tamil script
4. **Bengali (`bn`)** — Bengali-Assamese script
5. **Urdu (`ur`)** — Perso-Arabic / Nastaliq script & diacritics removal
6. **Mandarin (`zh`)** — Hanzi character-level tokenization
7. **English (`en`)** — Latin alphabet & case normalization

### 🎯 Critical Contract for Jay (Core ALM Temporal Fusion)

## 📦 How Jay Imports & Uses `ASRModel`

Jay's temporal fusion module can import and call `ASRModel.encode()` without knowing anything about internal ASR mechanics:

```python
import torch
from src.asr import ASRModel

# 1. Initialize ASR Model (CUDA or CPU)
asr = ASRModel(device="cuda" if torch.cuda.is_available() else "cpu")

# 2. Extract Speech Embeddings for Temporal Fusion
# audio can be a file path, raw bytes, numpy array, or torch tensor
audio_path = "path/to/threat_audio.wav"

# Frame-level embeddings: (Batch, Time_Frames, Embedding_Dim) e.g., (1, 150, 512)
frame_embeddings = asr.encode(audio_path)

# Pooled acoustic vector: (Batch, Embedding_Dim) e.g., (1, 512)
pooled_embedding = asr.encode(audio_path, pool=True)

# Full representation dictionary
features = asr.get_speech_embeddings(audio_path)
print("Frame Shape:", features["frame_embeddings"].shape)
print("Embedding Dim:", features["embedding_dim"].item())

# 3. Auxiliary Multilingual Transcription
transcript_result = asr.transcribe(audio_path, language="hi")
print("Transcribed Text:", transcript_result["text"])
print("Confidence:", transcript_result["confidence"])
print("Detected Language:", transcript_result["language"])
```

## 🛠️ CLI Tools & Execution

### 1. Multilingual Inference CLI
```bash
# Transcribe audio with automatic speech embeddings extraction
python -m src.asr.inference --audio samples/emergency_hi.wav --language hi --extract-embeddings

# Transcribe Mandarin audio
python -m src.asr.inference --audio samples/mandarin_sample.wav --language zh
```

### 2. Dataset Manifest Generator (< 2.5 GB Budget)
```bash
# Generate manifest from local directory
python -m src.training.manifest_generator --dir datasets/samples --lang hi --output datasets/manifests/hi_manifest.json

# Stream subset from IndicVoices (Hindi, Telugu, Tamil, Bengali, Urdu)
python -m src.training.manifest_generator --stream-indicvoices --max-samples 50
```

### 3. Model Training & Fine-Tuning
```bash
python -m src.training.train_asr \
  --dataset datasets/manifests/sample_multilingual_manifest.json \
  --epochs 5 \
  --batch-size 4 \
  --learning-rate 1e-4 \
  --device auto \
  --grad-accum 2 \
  --output checkpoints/asr_model
```

### 4. Standard WER / CER Evaluation
```bash
python -m src.asr.evaluate --eval-file evaluation/test_eval.json --output evaluation/report.json
```
